# 🏗️ HoroGrue Frontend

Interface Web de gestion pour l'entreprise **HoroGrue**.

Application web conçue avec **Angular**, **TypeScript** et **Bootstrap**.

---

## 📋 Aperçu du projet

Ce projet constitue la partie front-end de l'application HoroGrue. Il permet d'interagir avec les différents modules de gestion à travers une interface réactive et adaptée aux mobiles.

### Modules principaux

- 🔑 **Authentification** : Gestion des accès utilisateur.
- 📊 **Tableau de Bord** : Vue d'ensemble et alertes.
- 🚛 **Gestion des Véhicules** : Suivi de la flotte et du kilométrage.
- 👷 **Gestion du Personnel** : Suivi des collaborateurs et des qualifications.

---

## 🛠️ Technologies utilisées

- **Framework** : [Angular](https://angular.dev/)
- **Langage** : TypeScript
- **Styles** : Bootstrap 5 & Bootstrap Icons
- **HTTP & Flux** : RxJS & HttpClient

---

## 🚀 Installation & Lancement

### 1. Installation des dépendances

```bash
npm install
```

### 2. Démarrage en mode développement

```bash
npm run start
```

L'application est accessible par défaut sur `http://localhost:4200`.

### 3. Compilation

```bash
npm run build
```
